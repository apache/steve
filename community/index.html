Community

Apache STeVe is developed in the open at the Apache Software Foundation. Questions, bug reports, code contributions, and documentation improvements are welcome.

Mailing lists​

Use dev@steve.apache.org for questions about using STeVe and discussions about its development. Subscribe by sending an email to the subscription address, then follow the confirmation instructions.

Issues and contributions​

  • Report a bug or suggest an improvement on GitHub. Include the version or commit you are using and steps to reproduce the problem.
  • Browse the source and open a pull request. The getting started guide and documentation are useful starting points.
  • For a potential security vulnerability, follow the ASF security reporting process.

About the project​

STeVe grew out of the voting system used to elect the ASF Board of Directors. It is an Apache Software Foundation project, released under the Apache License, Version 2.0.
