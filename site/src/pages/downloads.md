# Downloads

Apache STeVe has not published an official release yet.

## Development source

The source is available in the [Apache STeVe Git repository](https://github.com/apache/steve):

```shell
git clone https://github.com/apache/steve.git
cd steve
```

The `trunk` branch contains development code. Repository snapshots are not official ASF releases.

Follow the [getting started guide](/getting-started/) to set up the v3 application or work with the tally tools.

## Release questions

Ask on the [development mailing list](/community/#mailing-lists) about release plans or how to get involved.
