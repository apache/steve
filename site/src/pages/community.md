# Community

Apache STeVe is developed in the open at the Apache Software Foundation. Questions, bug reports, code contributions, and documentation improvements are welcome.

## Mailing lists

Use **dev@steve.apache.org** for questions about using STeVe and discussions about its development. Subscribe by sending an email to the subscription address, then follow the confirmation instructions.

| List                                                    | Subscribe                                              | Unsubscribe                                                | Read the archives                                                               |
| ------------------------------------------------------- | ------------------------------------------------------ | ---------------------------------------------------------- | ------------------------------------------------------------------------------- |
| [Development](mailto:dev@steve.apache.org)              | [Subscribe](mailto:dev-subscribe@steve.apache.org)     | [Unsubscribe](mailto:dev-unsubscribe@steve.apache.org)     | [dev archives](https://lists.apache.org/list.html?dev@steve.apache.org)         |
| [Commit notifications](mailto:commits@steve.apache.org) | [Subscribe](mailto:commits-subscribe@steve.apache.org) | [Unsubscribe](mailto:commits-unsubscribe@steve.apache.org) | [commits archives](https://lists.apache.org/list.html?commits@steve.apache.org) |

These lists are public and their messages are publicly archived.

## Issues and contributions

- [Report a bug or suggest an improvement](https://github.com/apache/steve/issues) on GitHub. Include the version or commit you are using and steps to reproduce the problem.
- [Browse the source and open a pull request](https://github.com/apache/steve). The [getting started guide](/getting-started/) and [documentation](/documentation/) are useful starting points.
- For a potential security vulnerability, follow the [ASF security reporting process](https://www.apache.org/security/).

## People

STeVe is maintained by its community. The [ASF project roster](https://whimsy.apache.org/roster/committee/steve) lists the current PMC and committers, and the [contributor history](https://github.com/apache/steve/graphs/contributors) records contributions to the repository.

## About the project

STeVe grew out of the voting system used to elect the ASF Board of Directors. It is an Apache Software Foundation project, released under the [Apache License, Version 2.0](https://www.apache.org/licenses/LICENSE-2.0).
