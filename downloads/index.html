Development source​

The source is available in the Apache STeVe Git repository:

git clone https://github.com/apache/steve.git
cd steve

The trunk branch contains development code. Repository snapshots are not official ASF releases.

Follow the getting started guide to set up the v3 application or work with the tally tools.

Ask on the development mailing list about release plans or how to get involved.
